# IndustryGPT – Specialized LLM for Technical Support

##  Project Overview

IndustryGPT is a domain-specific conversational AI project designed to assist with technical support and IT infrastructure diagnostic queries.

The project uses a fine-tuned DistilGPT2 language model and provides an interactive Gradio-based user interface for testing model responses.

##  Objectives

- Build a specialized language model for technical support.
- Fine-tune DistilGPT2 on domain-specific technical data.
- Generate responses to IT infrastructure and troubleshooting queries.
- Provide an easy-to-use interface using Gradio.

##  Technologies Used

- Python
- PyTorch
- Hugging Face Transformers
- DistilGPT2
- Gradio
- Pandas
- NumPy
- Jupyter Notebook

##  Model

**Base Model:** DistilGPT2

**Fine-Tuning:** Domain-specific technical support data

**Training:** 25 epochs

##  Key Features

- Technical support query handling
- Domain-specific language model
- Fine-tuned DistilGPT2 architecture
- Interactive Gradio interface
- End-to-end model fine-tuning workflow
